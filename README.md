# Chat bot with memory and history


A simple command-line AI assistant built with LangChain and Groq using the GPT-OSS-20B model with chat history and memory

## Features

- Interactive AI chat
- Maintains conversation history
- Custom system prompt
- Configurable model temperature and response length
- Simple command-line interface

## Tech Stack

- Python
- LangChain
- Groq
- GPT-OSS-20B
- python-dotenv

## Usage

Run the Python file and type your message in the terminal.

Type `exit`, `bye`, or `stop` to end the conversation.
